## Markdown Cheat Sheet 
[Link to official documentation.](https://www.markdownguide.org/cheat-sheet/) 

### Most used symbols: 
- `#` - The hashtag symbol will create a **title** or **main heading**
- `##` - The double hashtag symbol will create a **subtitle** or **subheading**
- `*text*` - The `*` symbol needs to be around text to make text **italics**
- `**text**` - The `**` symbol needs to be around text to make text **bold**
- (`), The backtick symbol will create a **single line of code**
- (```), The triple backtick symbol will create a **block of code** or multiple lines of code
- `-`, The dash symbol will create a bulleted list, also known as an **unordered list**
- `1.`, The number with a . and a space will create a numbered list 
- `[text goes in here](link goes in here)`, This formatting will add a **link** to text 
- `![image description/ alt text](link goes in here)`, This formatting will add an **image** to your file
- `---`, The triple dashed line will create a **horizontal line break**
